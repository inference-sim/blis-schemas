# Model graph

<p class="lede">A model, written as the GPU work one forward pass launches. Each distinct
layer is a small directed acyclic graph of cost primitives. A stack says how the layers
repeat. The catalog derives one graph per model from the vendor's configuration and commits
it as <code>models/&lt;name&gt;/graph.yaml</code>.</p>

Graphs are generated by the catalog's `scripts/derive_graph.py`, never written by hand.
Why the schema takes this form, rather than following a vendor's configuration format, is
explained in [Why a model is a graph](../design/model-graph.md).

```yaml title="models/qwen3-14b/graph.yaml, abbreviated"
kind: ModelGraph
name: qwen3-14b
derived_from:
  format: hf_config_json
  path: config.json
  sha256: e73c3664ca09b10a673fef0c22e8a6b456201d49bd4713c9691f775720e8857a
  deriver_version: 1
global:
  hidden_size: 5120
  vocab_size: 151936
  tie_word_embeddings: false
  weight_dtype: bf16
layer_kinds:
- id: dense
  nodes:
  - {op: Elementwise, role: input_norm}
  - {op: GEMM, role: qkv_proj, n: 7168, k: 5120}
  - {op: Attention, kind: gqa, n_q: 40, n_kv: 8, d_h: 128}
  - {op: GEMM, role: o_proj, n: 5120, k: 5120}
  - {op: AllReduce, role: attn_out, emit: tensor_parallel}
  # ... the MLP: a norm, two GEMMs and a second AllReduce
  edges: [[0, 1], [1, 2], [2, 3], [3, 4], ...]
stack:
  pattern: [dense]
  repeat: 40
head:
- {op: Elementwise, role: final_norm}
- {op: GEMM, role: lm_head, n: 151936, k: 5120}
```

## Keys

<!-- fields: model.Graph -->

| Key | Type | Required | Meaning |
|---|---|---|---|
| `kind` | string | yes | Always `ModelGraph`. |
| `name` | string | yes | Must equal the model's directory name in the catalog. |
| `derived_from` | mapping | yes | The vendor file the graph was derived from, below. |
| `global` | mapping | yes | Whole-model shapes, below. |
| `layer_kinds` | list | yes | The distinct layers, at least one. |
| `stack` | mapping | yes | The order the layers run in. |
| `head` | list of nodes | no | Nodes after the stack, such as the final norm and the LM head. |
| `speculator` | mapping | no | A draft module, as its own stack. |
| `modality` | string | no | What the graph covers. Omitted means `text_only`. `text_decoder_of_multimodal` marks the decoder of a model whose encoder the graph does not price. See [modalities](vocabularies.md#modalities). |

### `derived_from`

<!-- fields: model.Derivation -->

| Key | Type | Required | Meaning |
|---|---|---|---|
| `format` | string | yes | The source format, such as `hf_config_json`. |
| `path` | string | yes | The source file, relative to the model directory. |
| `sha256` | string | yes | Digest of the source file, 64 characters. A change to the source without re-deriving is then detectable. |
| `deriver_version` | integer | yes | Version of the deriver that wrote the graph, at least 1. |

### `global`

<!-- fields: model.GlobalShape -->

| Key | Type | Required | Meaning |
|---|---|---|---|
| `hidden_size` | integer | yes | Model width, positive. |
| `vocab_size` | integer | yes | Vocabulary size, positive. |
| `tie_word_embeddings` | boolean | no | Whether the LM head shares the embedding weights. |
| `weight_dtype` | string | yes | The format parameters are stored in. One of the [dtypes](vocabularies.md#dtypes). |

### `layer_kinds`

<!-- fields: model.LayerKind -->

| Key | Type | Required | Meaning |
|---|---|---|---|
| `id` | string | yes | Unique within the graph. The stack refers to it. |
| `nodes` | list of nodes | yes | The primitives in this layer, at least one. |
| `edges` | list of pairs | no | `[from, to]` indices into `nodes`. The graph must be acyclic. |

### `stack`

--8<-- "docs/figures/stack.html"

<!-- fields: model.Stack -->

| Key | Type | Required | Meaning |
|---|---|---|---|
| `prologue` | list of strings | no | Layer kinds that run once, first. |
| `pattern` | list of strings | no | Layer kinds that repeat. |
| `repeat` | integer | if `pattern` is set | How many times `pattern` runs. |
| `epilogue` | list of strings | no | Layer kinds that run once, last. |

A uniform model is a one-entry pattern with a repeat. A model with no period puts its
whole layer sequence in `prologue` and leaves `repeat` at zero. The stack must expand to at
least one layer.

### `speculator`

<!-- fields: model.Speculator -->

| Key | Type | Required | Meaning |
|---|---|---|---|
| `method` | string | yes | The engine's name for the speculative method. The rules pack checks it. |
| `num_spec_tokens` | integer | yes | Draft tokens per step, at least 1. |
| `stack` | mapping | yes | The draft module's own stack over the graph's layer kinds. Needs a `pattern` and a `repeat` of at least 1. Its names are not checked against `layer_kinds`. |

The draft module is a stack and not a token count because, for an MoE target, the draft
pass is itself an MoE pass with its own cost.

## Nodes

A node is one primitive with the shape parameters that primitive prices. There are nine
primitives:

--8<-- "docs/generated/enum/model.Op.md"

The four collectives (`AllReduce`, `AllGather`, `ReduceScatter`, `All2All`) exist or not
depending on the deployment's layout, so each must carry an `emit` condition. The tables
below group a node's keys by the primitive that prices them. Some keys are rejected on a
primitive that does not price them, such as a head count or an expert count on a `GEMM`.
That check covers the likely mistakes, not every key.

## Model identity

The catalog commits `models/<name>/model.yaml` beside the graph. It records which model
the entry is and where its `config.json` came from.

```yaml title="models/qwen3-14b/model.yaml"
--8<-- "testdata/models/qwen3-14b/model.yaml"
```

<!-- fields: model.Identity -->

| Key | Type | Required | Meaning |
|---|---|---|---|
| `name` | string | yes | Must equal the model's directory name. |
| `source` | mapping | yes | Where the vendor configuration was fetched from, below. |

### `source`

<!-- fields: model.Source -->

| Key | Type | Required | Meaning |
|---|---|---|---|
| `provider` | string | yes | The hosting service, such as `huggingface`. |
| `repo` | string | yes | The repository on that service. |
| `revision` | string | yes | The exact revision the configuration was taken at. |
| `retrieved` | string | no | The date it was fetched. |

`model.yaml` and `graph.yaml` do not accept `_comment` keys, unlike the chip, fabric,
storage-class and workload-shape files.

## Checks

A graph is invalid if

- `kind` is not `ModelGraph`, `name` is empty, or `modality` is not recognized;
- `derived_from` lacks `format` or `path`, its `sha256` is not 64 characters long, or its
  `deriver_version` is below 1;
- `hidden_size` or `vocab_size` is below 1, or `weight_dtype` is not a recognized dtype;
- there are no layer kinds, or a layer kind has an empty or duplicate `id` or no nodes;
- an edge indexes a node that does not exist, joins a node to itself, or closes a cycle;
- the stack expands to no layers, `repeat` is negative, a pattern has no repeat or a repeat
  no pattern, or the stack names a layer kind that is not declared;
- a `speculator` lacks a `method`, a `pattern`, at least one draft token or a repeat of at
  least 1;
- any node, in a layer kind or the head, is invalid.

A node is invalid if

- `op` or `emit` is not recognized, or a collective has no `emit`;
- a key the tables mark required for its primitive is missing or not positive;
- `top_k` exceeds `experts`, `shared_intermediate_size` is set without `shared_experts`, or
  `shared_experts`, `shared_intermediate_size`, `latent_size` or `bytes_per_token` is
  negative;
- an attention `kind` or `recurrent_kind` is not recognized, `n_kv` exceeds `n_q`, or `n_kv`
  is not 1 for `mla` or `sparse_mla`;
- `weight_dtype` is set on anything other than a `GEMM` or `GroupedGEMM`, or it or
  `state_dtype` is not a recognized dtype;
- `index_topk` or `compress_ratio` is set on anything other than a `sparse_mla` attention
  node, or is negative;
- it carries one of the keys its primitive rejects, such as `n_q` on a `GEMM`.

Two problems are warnings: a layer kind that neither the stack nor the speculator uses,
and an `emit` condition on a node that is not a collective.

A model identity is invalid if `name` is empty, `source` is absent, or `source` lacks a
`provider`, `repo` or `revision`.

`validate-catalog` also checks that `name` in both `graph.yaml` and `model.yaml` equals the
directory name.
